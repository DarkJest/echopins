## EchoPins 1.0.0

Первый релиз. Minecraft 1.21.1, NeoForge, требуется Simple Voice Chat 2.6.20+.

### Голосовые пины

- Запись короткого голосового сообщения с привязкой к грани блока или к точке в мире.
- Запись по удержанию клавиши (по умолчанию `B`), с предпросмотром и подтверждением перед
  сохранением.
- Необязательная текстовая подпись, она же запасной вариант для тех, кому неудобно слушать.
- Видимость «для всех» или «лично», получатели выбираются по UUID.
- Короткий, обычный или бессрочный срок хранения — в рамках настроек сервера.

### Обнаружение и воспроизведение

- Компактные метки в мире, проявляющиеся в радиусе обнаружения, с масштабированием по расстоянию и
  настраиваемым поведением за стенами.
- Подпись с автором, возрастом, длительностью, текстом и видимостью при наведении.
- Позиционное воспроизведение через Simple Voice Chat, слышное только тем, кому это разрешено.
- Отдельная категория громкости **EchoPins**.
- Экран входящих: «Рядом», «Мои», «Личные», «Новые», с отметками о прослушивании.

### Сервер

- Пространственный индекс по чанкам — никакого перебора всех пинов каждый тик.
- Подписки по игрокам: снимок состояния плюс дельты, пересчёт только при переходе через границу
  чанка.
- 32 серверных и 16 клиентских параметров, у всех проверяется диапазон.
- Ограничение частоты запросов (token bucket) плюс отдельные задержки на создание и прослушивание.
- Лимиты на игрока, на сервер, на одно место и на общий объём хранилища.
- Постепенная очистка истёкших пинов и потерянных аудиофайлов.
- Полное дерево команд для игроков и администраторов.

### Хранение

- Контейнер `.epv`: версионируемый, с CRC-32 и проверкой границ, хранит кадры Opus как есть, без
  перекодирования.
- Атомарная запись; незавершённые временные файлы удаляются при запуске.
- Метаданные создаются только после того, как аудио надёжно записано на диск.
- Версия схемы у каждого пина и механизм миграций, доступный с первой версии.

### Приватность

- Запись только во время явной сессии с видимым индикатором. Никакой фоновой записи.
- Записывается только голос самого автора.
- По умолчанию записываемый голос не транслируется окружающим игрокам.
- Сессия завершается при отключении, смерти, смене измерения, достижении лимита длины или тишине.
- Неподтверждённые записи удаляются автоматически.

### Известные ограничения

- **В режиме push-to-talk нужно держать клавишу голосового чата вместе с клавишей EchoPins.**
  Публичный API Simple Voice Chat отдаёт звук с микрофона только когда мод уже передаёт его, а
  штатного способа начать захват извне нет. Индикатор записи об этом сообщает и показывает, идёт ли
  звук.
- Аудио хранится в сохранении мира без шифрования, администратор сервера может его прослушать. Это
  описано в `PRIVACY.md` прямо, а не спрятано.
- В версии 1.0 поддерживается только Simple Voice Chat.
- Изображения в галерее — помеченные макеты интерфейса, настоящие скриншоты ещё предстоит сделать.
- Ручная матрица тестов с несколькими клиентами ещё не пройдена целиком.
