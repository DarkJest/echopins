# EchoPins 1.1.1

Исправление надёжности для Minecraft 1.21.1 на **Fabric и NeoForge**.

- Лимит аудиохранилища теперь атомарен даже при одновременном сохранении записей.
- Закрыты гонки записи и воспроизведения при выходе, смерти, переходе через портал и остановке сервера.
- После чтения аудио повторно проверяются доступ, расстояние, измерение и подключение к голосовому чату.
- Добавлена серверная ray-trace проверка блока, к которому прикрепляется пин.
- Данные мира из более новой схемы больше не перезаписываются старой версией мода.
- Исправлены пакеты больших списков игроков и публикация двух loader-JAR.
- Обновлены баннеры, явно помеченные UI-мокапы и инструкция установки.

Скачайте JAR для своего загрузчика. Для Fabric также нужен Fabric API.
