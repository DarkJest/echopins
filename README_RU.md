Друг вышел из игры. Через три часа вы приходите на базу и находите сундук с железом,
недостроенную машину и никаких объяснений.

EchoPins это решает. Запишите короткое голосовое сообщение, оставьте его прямо на сундуке — и тот,
кто подойдёт следующим, услышит его. Неважно, в сети вы или нет.

## Что это такое

EchoPins — это **асинхронные голосовые сообщения, привязанные к местам в мире**.

Это *не* замена голосовому чату, *не* мод на путевые точки и *не* Discord внутри Minecraft.
Мод делает одну вещь: позволяет прикрепить короткую голосовую заметку к месту, чтобы друзья
нашли её позже.

```
У сундука     «Железо пока не трогайте, оно нужно для реактора.»
У портала     «Этот выходит рядом с крепостью.»
В шахте       «Я пошёл налево. Справа спавнер.»
У механизма   «Эту линию пока не включайте, она не подключена.»
```

## Возможности

- **Заметки, привязанные к месту** — к грани блока или к точке в пространстве.
- **Работает офлайн** — автору не нужно быть в сети.
- **Ничего лишнего на экране** — небольшая метка проявляется при приближении, и всё.
- **Для всех или лично** — можно выбрать, кто именно услышит сообщение.
- **Подписи** — необязательный текст рядом с записью, он же вариант для тех, кому неудобно слушать.
- **Свой ползунок громкости** — отдельная категория громкости в Simple Voice Chat.
- **Срок хранения** — сообщения удаляются сами, мир не разрастается бесконечно.
- **Рассчитан на реальные серверы** — пространственный индекс, подписки по игрокам, ограничение
  частоты запросов и лимиты хранилища.

## Как это работает

1. Посмотрите на нужное место.
2. Зажмите клавишу **Создать EchoPin** (по умолчанию `B`).
3. Скажите, что хотели. Отпустите клавишу.
4. Выберите «для всех» или «лично», при желании добавьте подпись и сохраните.

Друзья увидят небольшую метку, когда подойдут ближе, и нажмут одну клавишу, чтобы послушать.

## Установка

### Клиент

1. Установите NeoForge 21.1.x либо Fabric Loader и Fabric API для Minecraft 1.21.1.
2. Положите **Simple Voice Chat** и **EchoPins** в папку `mods/`.
3. Запустите игру. Клавиши можно переназначить в *Настройки → Управление → EchoPins*.

### Сервер

1. Установите NeoForge 21.1.x либо Fabric Loader (и Fabric API).
2. Положите оба мода в `mods/`.
3. Запустите сервер один раз, чтобы создался `config/echopins-server.toml` (на Fabric — `.json`).
4. Перед открытием сервера для всех прочитайте [docs/SERVER_SETUP.md](docs/SERVER_SETUP.md).

## Важно: как работает запись

**EchoPins не может включить ваш микрофон.** Публичный API Simple Voice Chat отдаёт звук с
микрофона только тогда, когда мод уже передаёт его, и штатного способа начать захват извне нет.
Лезть во внутренности мода ради этого — ненадёжно и неправильно с точки зрения приватности.

На практике:

- **Активация голосом:** всё работает как ожидается. Зажали клавишу и говорите.
- **Push-to-talk:** держите клавишу EchoPins **и** свою обычную клавишу голосового чата
  одновременно. Индикатор записи об этом напоминает и показывает, идёт ли звук вообще.

Пока вы записываете EchoPin, ваш голос **не** транслируется игрокам рядом (серверный параметр
`suppressProximityBroadcastWhileRecording`, включён по умолчанию). Оставить заметку — это не то же
самое, что разговаривать с теми, кто случайно стоит поблизости.

## Приватность

EchoPins записывает голос, поэтому напишем прямо, а не мелким шрифтом:

- Запись идёт **только** пока зажата клавиша. Никакой фоновой или скрытой записи.
- Индикатор виден всё время записи, есть звуки начала и конца.
- Записывается **только ваш** голос — не другие игроки и не окружающий разговор.
- Аудио хранится **на сервере**, внутри сохранения мира. Файлами распоряжается администратор
  сервера — ровно так же, как и всем остальным содержимым мира.
- Отмена удаляет запись, неподтверждённые записи удаляются автоматически.

Подробности, включая то, как удалить свои сообщения и как администратору очистить хранилище, —
в [PRIVACY.md](PRIVACY.md).

## Настройка сервера

Всё в `config/echopins-server.toml`, на Fabric — в `config/echopins-server.json`. Значения по умолчанию подобраны так, чтобы мод «из коробки»
не мог забить диск: сообщения живут неделю, хранилище ограничено 1 ГиБ, создание и прослушивание
ограничены по частоте.

| Параметр | По умолчанию | Что делает |
|---|---|---|
| `maxRecordingSeconds` | `30` | Максимальная длина сообщения |
| `defaultExpiryHours` | `168` | Неделя; `0` — не удалять |
| `allowPermanentPins` | `true` | Можно ли отключить срок хранения |
| `maxPinsPerPlayer` | `64` | Лимит на игрока |
| `maxTotalPins` | `5000` | Лимит на сервер |
| `discoveryRadius` | `56` | С какого расстояния видны метки |
| `maxTotalAudioStorageBytes` | `1 ГиБ` | Жёсткий предел хранилища |

Все параметры описаны в [docs/CONFIGURATION.md](docs/CONFIGURATION.md).

## Команды

```
/echopins list                     Пины рядом
/echopins mine                     Ваши пины
/echopins unread                   Непрослушанные
/echopins stats                    Статистика
/echopins delete <id>              Удалить свой пин
```

Для администраторов (по умолчанию уровень прав 2):

```
/echopins admin stats
/echopins admin delete <id>
/echopins admin purge expired
/echopins admin purge player <игрок>
/echopins admin cleanup
/echopins admin reload
```

Подробности — в [docs/COMMANDS.md](docs/COMMANDS.md).

## Вопросы

**Автор должен быть в сети?**
Нет. В этом и смысл.

**Нужно быть в группе голосового чата?**
Нет. Simple Voice Chat используется просто как канал для звука.

**Меня слышат, пока я записываю?**
Нет, по умолчанию. См. раздел о записи выше.

**Сколько это занимает на диске?**
Примерно 2 КБ на секунду речи. Тысяча десятисекундных сообщений — около 20 МБ, и есть жёсткий
лимит.

**Работает в Нижнем мире, Крае и модовых измерениях?**
Да. Пин хранит своё измерение и появляется только в нужном.

**Не будет ли лагать сервер?**
В простое мод почти ничего не стоит. Пины индексируются по чанкам, каждому игроку отправляются
только ближайшие, работа с диском вынесена с серверного потока. См.
[docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

**Можно вместо этого Plasmo Voice?**
В версии 1.0 — нет. Бэкенд спрятан за адаптером, так что добавить другой можно позже.

## Совместимость

- Работает на выделенном сервере и в одиночной игре.
- Никаких миксинов в Minecraft или Simple Voice Chat и никакой рефлексии в его внутренности —
  только опубликованный API плагинов. Именно поэтому мод безопасен в большой сборке.
- Не регистрирует блоки, предметы, сущности и генерацию мира. Конфликтовать не с чем.
