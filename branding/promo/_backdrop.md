# About the images in this folder

These are **UI mockups**, not gameplay screenshots.

They were produced by rendering the mod's real interface geometry, colours, strings and layout
rules as vector art. `world-pin`, `recording`, and `inbox` use an AI-assisted promotional voxel
backdrop; `private-pin` keeps the original abstract vector backdrop. Every panel, label, colour
and piece of copy matches what the mod draws, but the world behind them is not a Minecraft render.

Each image carries a visible `UI MOCKUP` tag for exactly this reason. The AI-assisted images say
so in that tag as well. They are safe to use in a
README or on a project page as illustrations of the interface, and they must **not** be presented
as screenshots of the game.

Real screenshots still need to be captured in-game. See [`../SCREENSHOT_PLAN.md`](../SCREENSHOT_PLAN.md)
for the shot list, composition notes and alt text to use when replacing these.
